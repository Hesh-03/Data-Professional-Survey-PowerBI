## Dashboard Preview

![Dashboard](Images/dashboard.png)

## Project Overview

This dashboard analyses survey responses from data professionals using Microsoft Power BI.

### Features

- Average Salary by Job Title
- Favourite Programming Languages
- Country Distribution
- Work-Life Balance
- Salary Happiness
- Difficulty Breaking into Data

### Tools Used

- Microsoft Power BI
- Power Query
- DAX

### Dataset

Data Professional Survey Dataset
